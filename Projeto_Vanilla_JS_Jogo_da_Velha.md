# Projeto em Vanilla JavaScript -- Jogo da Velha

## O que é Vanilla JavaScript?

**Vanilla JavaScript** é o desenvolvimento utilizando apenas as
tecnologias nativas da Web, sem o uso de frameworks ou bibliotecas como
React, Angular ou Vue. O projeto é construído somente com:

-   **HTML**: estrutura da página.
-   **CSS**: estilização e aparência.
-   **JavaScript**: lógica e interatividade.

## Sobre o projeto

O projeto desenvolvido é um **Jogo da Velha** totalmente em Vanilla
JavaScript.

### Estrutura

-   **HTML:** cria o tabuleiro, o texto de status e o botão de
    reiniciar.
-   **CSS:** aplica um visual moderno, responsivo, animações, efeitos de
    hover e cores para os jogadores **X** e **O**.
-   **JavaScript:** controla toda a lógica do jogo, incluindo:
    -   Alternância entre os jogadores;
    -   Verificação das condições de vitória;
    -   Detecção de empate;
    -   Atualização do status da partida;
    -   Reinício do jogo.

## Conclusão

Este projeto demonstra como é possível desenvolver uma aplicação web
completa utilizando apenas HTML, CSS e JavaScript puro (Vanilla JS),
servindo como uma excelente base para aprender os conceitos fundamentais
do desenvolvimento Front-end antes da utilização de frameworks.
